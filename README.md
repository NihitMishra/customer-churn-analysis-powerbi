# Customer Churn Analysis | Power BI

## Project Overview
This project analyzes customer churn in the telecommunications industry using Power BI. The goal is to understand customer behavior, identify patterns associated with churn, and generate insights that can help improve customer retention.

## Business Objectives
- Analyze the overall customer churn rate.
- Identify customer segments with higher churn.
- Understand how contract types and monthly charges relate to churn.
- Present findings through an interactive Power BI dashboard.
- Recommend strategies to improve customer retention.

## Tools & Technologies
- **Power BI Desktop** — data visualization and dashboard development
- **Power Query** — data cleaning and transformation
- **Microsoft Excel** — dataset storage and inspection

## Dataset
The project uses a telecommunications customer dataset containing customer demographics, subscribed services, contract details, billing information, and churn status.

## Key Analysis Areas
- Customer churn distribution
- Churn by contract type
- Monthly charges and tenure
- Customer service and subscription patterns

## Business Value
The analysis aims to help businesses understand why customers leave, identify potentially at-risk customer segments, and make data-informed retention decisions.
